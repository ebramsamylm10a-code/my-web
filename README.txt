GENERATIVE AI WEBSITE
=====================

محتويات المشروع:
- index.html: الصفحات الخمس ومحتواها.
- style.css: الألوان والتنسيق والتجاوب مع الموبايل والحركات.
- script.js: التنقل بين الصفحات والبدء من أعلى كل صفحة.
- assets/: الشعارات المرفوعة، لوحة الألوان، وصورة الروبوت.

طريقة النشر على GitHub Pages:
1) فك ضغط الملف.
2) أنشئ Repository جديد على GitHub.
3) ارفع index.html و style.css و script.js ومجلد assets كما هي (لا ترفع ملف ZIP فقط).
4) من Settings > Pages اختر Deploy from a branch ثم main و / (root).
5) احفظ وانتظر رابط الموقع الذي سيظهر في إعدادات Pages.

إضافته إلى Google Sites:
1) بعد نشر الموقع على GitHub Pages انسخ رابط الموقع.
2) افتح Google Sites ثم Insert > Embed > By URL.
3) الصق رابط GitHub Pages واضغط Insert.
4) وسّع إطار التضمين داخل الصفحة واحفظ/انشر الموقع.

ملاحظات:
- الموقع صفحة HTML واحدة تعرض 5 شاشات مستقلة مع أزرار السابق والتالي ونقاط التنقل.
- أزرار "زيارة الموقع" تفتح المواقع الرسمية في تبويب جديد.
- الخطوط تستخدم Google Fonts عند توفر الإنترنت، مع خطوط بديلة عند عدم توفره.
- الروبوت صورة مولدة خصيصًا لهذا التصميم.
- قد تختلف خصائص أدوات الذكاء الاصطناعي باختلاف الخطة والإصدار والمنطقة.
